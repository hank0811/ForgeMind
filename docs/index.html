◆ ForgeMind

A deterministic engine for multi-agent software engineering

ForgeMind runs a task through six specialized AI roles with real governance approval gates and bounded retries. Python owns every state transition; each AI role only ever reports a fact about one bounded stage — never a decision.

View source on GitHub Read the README

The pipeline

Analyst→ Architect-Planner→ Implementer→ Tester→ Reviewer→ Finalizer

What it actually is

A deterministic state machine

An explicit, exhaustively-tested transition table decides every state change — not an LLM's judgment call.

Rule-based governance

Plans and final results are checked against explicit sensitive-action patterns and paused for human approval when they match — never trusting an agent's self-report.

Two real interfaces

A CLI (forgemind new/run/status/approve/reject) and a local website, both driving the identical orchestrator — neither one duplicates the other's logic.

Markdown artifacts, no database

Every stage's output is a Markdown file with YAML frontmatter. No ORM, no schema migrations, no hidden state.

Run it for real

git clone https://github.com/hank0811/ForgeMind.git
cd ForgeMind
pip install -e ./engine
pip install -r webapp/backend/requirements.txt
python webapp/backend/app.py
# open http://127.0.0.1:5000

Full setup, configuration, and the CLI's own commands are documented in the repository README.
